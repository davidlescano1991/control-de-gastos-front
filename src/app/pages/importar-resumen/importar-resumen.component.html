help_center

Reglas y Consideraciones de Importación

info
1. Validación Antiduplicación Estricta

Antes de ingresar cualquier movimiento a PostgreSQL, el sistema contrasta la referencia y cuota frente a todos los ítems que ya existen en {{ mesesDisponibles[selectedMonth - 1].nombre }} {{ selectedYear }} para {{ selectedEntidadDestino() }}. Si una compra como "MPago 1/3" o "Impuestos" ya está cargada, se omite de forma segura para no duplicar montos.

2. Aislamiento de Pagos Anteriores

Los movimientos que representan pagos informados por el banco (ej. "Pago de tu tarjeta", "SU PAGO", montos negativos) no se computan como gastos. Se guardan en un registro histórico especial y se muestran en Mensual como dato informativo.

3. Conectividad y Base de Datos en Pausa

El botón solo se activa cuando la API backend está conectada. Si la instancia de Cloud SQL está en pausa, el sistema te avisará amablemente en lugar de romper la pantalla.
