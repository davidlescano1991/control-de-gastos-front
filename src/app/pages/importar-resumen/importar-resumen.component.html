Plan Maestro de Migración (Fase 6.23)

El próximo subpaso implementará el endpoint en la API backend para recibir los {{ movimientos.length }} movimientos detectados correspondientes a {{ selectedEntity.name }} y registrarlos automáticamente en los ítems mensuales de {{ mesesDisponibles[selectedMonth - 1].nombre }} {{ selectedYear }} en la base de datos PostgreSQL.

Validación Antiduplicación: Antes de insertar, el sistema verificará si cada ítem ya existe en dicho mes (ej. "Impuestos" o compras en cuotas como "MPago 1/3") para omitirlo de forma segura y evitar duplicar montos.

Aislamiento de Pagos Anteriores: Los pagos informados por el banco (ej. "Pago de tu tarjeta" o créditos negativos del mes previo) se guardarán de forma separada como dato informativo y no se computarán en los gastos ni en la deuda a pagar del mes.

Conectividad y Base de Datos en Pausa: La importación requiere que la API esté conectada. Además, si la base de datos PostgreSQL se encuentra pausada en Google Cloud para ahorro de costos, el sistema notificará claramente este estado para que pueda reanudarse antes de registrar los datos.

Mientras se completa la fase del backend, ya puedes previsualizar y descargar el Excel con los movimientos y cuotas agrupadas.
